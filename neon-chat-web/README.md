# NEON CHAT Web

A premium neon gaming-style chat interface for the web.

## Deploy
The GitHub Actions workflow `.github/workflows/neon-chat-web.yml` deploys the static website with GitHub Pages.
In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions** if it is not already selected. Then open **Actions → Deploy NEON CHAT Web → Run workflow**.

## Scope
This is a front-end demo. Messages you type appear in the selected channel in the current page only. It does not yet deliver messages to other users or persist after refresh. A backend is needed for live multi-user chat.
