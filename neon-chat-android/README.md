# NEON CHAT — Android

Premium neon-themed Android chat UI starter project.

## Build an APK
1. Open the repository's **Actions** tab.
2. Select **Build NEON CHAT Android APK**.
3. Click **Run workflow** on the main branch.
4. Open the completed run and download **NEON-CHAT-Android-APK** under Artifacts.
5. Extract the ZIP and install the APK on an Android device.

## Current scope
This first version is a local UI prototype. Messages you type are shown in the current screen only. It does not yet send messages to other people; real accounts and cross-device messaging require a backend.
